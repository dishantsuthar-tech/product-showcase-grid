# 🛍️ Product Showcase Grid

A responsive product showcase website built using **HTML and CSS**, featuring a modern product grid layout, consistent product images, and interactive hover effects.

## 🚀 Live Demo

🔗 [Product Showcase Grid](https://dishantsuthar-tech.github.io/product-showcase-grid/)

## ✨ Features

- Responsive product layout using CSS Grid
- Dynamic columns using `repeat()`, `auto-fit`, and `minmax()`
- Consistent image dimensions using fixed height and `object-fit: cover`
- Product cards with images, descriptions, and prices
- Flexbox for card content alignment
- Hover animations and shadow effects
- Responsive layout for different screen sizes
- Clean and simple UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Transitions
- CSS Transforms

## 📚 What I Learned

- Implementing responsive layouts using CSS Grid
- Understanding `auto-fit` and `minmax()`
- Combining CSS Grid and Flexbox
- Maintaining consistent image dimensions
- Using `object-fit: cover` to crop images without distortion
- Aligning card content using `margin-top: auto`
- Creating hover effects using `transform` and `box-shadow`
- Using CSS transitions for smooth animations
